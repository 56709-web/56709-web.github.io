# พอร์ตโฟลิโอ ศศกร ศรีหาเหง่า (Sasakorn Sirhangao)

เว็บพอร์ตโฟลิโอ: https://56709-web.github.io/

## แก้ไขเว็บ

- `index.html` คือหน้าเว็บทั้งหมด (HTML, CSS และ JavaScript อยู่ในไฟล์เดียว) มีคอมเมนต์ภาษาไทยบอกจุดที่แก้ได้
- `photo.jpg` รูปโปรไฟล์ในส่วนเปิด (สัดส่วนราว 9:10)
- `depa-award.jpg` รูปรับรางวัลในการ์ดผลงาน depa (สัดส่วน 16:10)

แก้ไฟล์แล้วอัปโหลดทับใน repository นี้ เว็บจะอัปเดตเองภายในไม่กี่นาที
